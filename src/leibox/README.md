## Elastic Panel Resize (active)

- Source: https://leibox.pantoria.cn/docs/animations/elastic-panel-resize
- LeiBox independent DOM/SVG implementation; design reference by Alvish: https://x.com/alvish/status/2111084319716647114/video/1
- Full source is retained in `elastic-panel-resize/`. Original reference video/source is not redistributed; the catalog permits distribution of the LeiBox package.
- Adapted to a right-side profile drawer. Pixel width limits replace demo percentages; native dialog supplies focus containment. The original spring, bend and stretch interaction remains; click, Escape, keyboard resize and mobile layout are integrated.
